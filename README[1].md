# Nursing Study Sanctuary 🌿

Free static website for GitHub Pages.

## Publish
1. Create a public GitHub repository named `nursing-study-sanctuary`.
2. Upload `index.html` to the repository root and commit it.
3. Go to Settings → Pages → Build and deployment.
4. Choose Deploy from a branch, `main`, and `/ (root)`, then Save.
5. Visit the GitHub Pages URL shown in Settings → Pages after deployment.

Features: focus timer, synthesized nature ambience, 10 practice questions, 6 flashcards, personal tasks and notes saved locally. No login, live collaboration, or server database. Do not enter confidential patient information.
